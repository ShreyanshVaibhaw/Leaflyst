# Security policy

Report suspected vulnerabilities privately to `security@leaflyst.dev` with the affected component, reproduction steps, and expected impact.

Do not access another customer's data, disrupt service, or include live credentials or secrets in a report. We will acknowledge reports within three business days, keep reporters informed during investigation, and coordinate remediation and disclosure timing.

Supported releases receive security fixes on the current minor release line. Credential values must never be submitted as test evidence; use fingerprints or synthetic credentials only.
